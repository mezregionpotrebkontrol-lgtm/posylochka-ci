# Что сделать после обновления CRM (октябрь 2026)

Код уже готов. Ниже шаги, которые можно сделать только вам: в кабинетах сервисов и в панели хостинга.
Выполняйте их по порядку. Шаги 1–2 срочные.

## 1. Перевыпустить токен Green API (срочно)

Старый токен MAX был виден всем в открытом репозитории. Его нужно сменить.

1. Откройте console.green-api.com → «Мои инстансы» → инстанс MAX.
2. Нажмите «Сменить токен» (Reset apiTokenInstance). Старый токен перестанет работать.
3. На хостинге откройте файл `crm/config.php` (ispmanager → Менеджер файлов → папка сайта → `crm`).
   В блоке `'green_api'` вставьте новый `apiTokenInstance`. `idInstance` не меняется.
4. Отправьте себе тестовую заявку с сайта и проверьте, что уведомление в MAX пришло.

Файл `config.php` на сервере автоматическая выгрузка не перезаписывает. Ключи хранятся только там.

## 2. Сделать репозиторий закрытым (срочно)

GitHub → репозиторий `posylochka-ci` → Settings → внизу «Danger Zone» → **Change visibility** → **Private**.
Автоматическая выгрузка на хостинг продолжит работать.

## 3. Обновить базу данных (один раз)

1. ispmanager → «Базы данных» → `u3661226_posylochka_crm` → phpMyAdmin.
2. Вкладка **SQL**. Вставьте содержимое файла `crm/install/migration-013-audit-promo-consent.sql` и нажмите «Вперёд».

Пока миграция не выполнена, CRM работает как раньше. Новые разделы покажут подсказку, что их нужно подключить.

## 4. Включить задания по расписанию

ispmanager → **Планировщик CRON** → «Создать задание». Создайте три задания.
Сначала уточните версию PHP сайта (ispmanager → «Сайты» → ваш сайт) и имя папки сайта в менеджере файлов.
Ниже указан вариант для PHP 8.3.

| Что | Расписание | Команда |
|---|---|---|
| Резервная копия базы | каждый день в 03:10 | `/opt/php/8.3/bin/php -f /var/www/u3661226/data/www/моя-посылочка.рф/crm/cron/backup.php` |
| Напоминания и сводка | каждый день в 10:00 | `/opt/php/8.3/bin/php -f /var/www/u3661226/data/www/моя-посылочка.рф/crm/cron/reminders.php` |
| Карта сайта | раз в неделю, пн 04:20 | `/opt/php/8.3/bin/php -f /var/www/u3661226/data/www/моя-посылочка.рф/crm/cron/sitemap.php` |

Если папка сайта в менеджере файлов называется `xn----8sb3addmbbgv2e2b8b.xn--p1ai`, подставьте это имя вместо `моя-посылочка.рф`.

Проверка: CRM → **Копии базы**. На следующий день там должна появиться свежая копия с зелёной отметкой «в порядке».
**Раз в неделю скачивайте копию себе** (компьютер или Яндекс Диск). Копия на том же хостинге не спасёт, если пропадёт сам хостинг.

## 5. Загрузить файлы в корень сайта

Из папки `site-root/` этого репозитория загрузите в корень сайта (туда, где лежит `index.html`) через менеджер файлов:

- `robots.txt` — подсказки для Яндекса и Google;
- `sitemap.xml` — карта сайта (дальше обновляется сама, см. шаг 4);
- `politika.html` — политика обработки персональных данных. **Перед загрузкой впишите ИНН и ОГРНИП** вместо `[УКАЖИТЕ ИНН]` и `[УКАЖИТЕ ОГРНИП]`. Текст — шаблон, его стоит показать юристу;
- `consent.js` — галочка согласия на обработку данных во всех формах.

Из папки `site-root-api/` загрузите в папку `api` на сайте новый файл `check_promo.php`. Он нужен для проверки промокодов с сайта.

## 6. Подключить галочку согласия на страницах сайта

В файлы `index.html`, `dostavka.html` и `app.html` добавьте перед `</body>` одну строку:

```html
<script src="/consent.js" defer></script>
```

Откройте сайт и проверьте, что у форм с телефоном появилась галочка.
Когда убедитесь, что галочка есть везде, в `crm/config.php` на сервере поставьте `'require_pd_consent' => true`.
Тогда сервер будет отклонять заявки без согласия.

## 7. Сообщить в Яндекс и Google о карте сайта

- Яндекс Вебмастер → ваш сайт → «Индексирование» → «Файлы Sitemap» → добавить `https://моя-посылочка.рф/sitemap.xml`.
- Google Search Console → «Файлы Sitemap» → тот же адрес.

## 8. Уточнить ставку НДС в чеках

Сейчас в чеках ЮKassa стоит «без НДС» (`vat_code => 1`, подходит для УСН без НДС и патента).
Если вы на УСН и с 2025 года платите НДС 5% или 7%, либо на ОСНО, уточните ставку у бухгалтера.
Затем в `crm/config.php` на сервере, в блоке `'yookassa'`, добавьте строку:
`'vat_code' => 7` (НДС 5%), `8` (НДС 7%) или `4` (НДС 20%).

## Что появилось в CRM

- **Постраничный просмотр** во всех списках: заявки, клиенты, финансы, претензии, заявки с сайта. Старые записи больше не теряются.
- **«Скачать в Excel»** в этих же списках. Выгружается всё, что подходит под текущие фильтры. В «Финансах» добавлен фильтр по датам, удобно для бухгалтера.
- **Промокоды** (меню «Промокоды», только администратор). Скидка в процентах или рублях, срок действия, лимит использований, минимальная сумма.
  Применяются в карточке заявки и при онлайн-оплате на сайте (поле `promo_code`).
- **Журнал** (только администратор): кто из сотрудников что менял, входы в систему, выгрузки.
  После 8 неверных паролей подряд вход с этого адреса блокируется на 15 минут.
- **Копии базы** (только администратор): список копий, «Сделать копию сейчас», скачивание.
- **Напоминания клиентам** в MAX и на почту: о неоплаченном счёте, о посылке, которая ждёт в пункте выдачи, о просроченном платеже по рассрочке.
  **Ежедневная сводка вам**: зависшие заявки, долги по постоплате, сроки ответа на претензии, долгое хранение на складе.
- **Чеки 54-ФЗ**: если у клиента нет ни телефона, ни email, чек уходит на почту магазина, и оплата не срывается.
- **Защита журналов**: файлы `*.log` в папке CRM (там телефоны клиентов) больше нельзя открыть по ссылке.
